# Codin-Digital

Portfolio-Website für Codin-Digital: Webdesign, AI Automation Engineering und Forward Deployment Engineering.

## Lokal ansehen

`index.html` im Browser öffnen. Die Website besteht aus statischem HTML, CSS und JavaScript und benötigt keinen Build.

## Enthalten

- Deutsche und englische Inhalte mit Sprachumschalter
- Interaktive Pixel-Hero und Animationen zwischen den Abschnitten
- Webdesign-Vorschau mit Desktop-/Mobile-Umschaltung
- Portfolio, vertikale Timeline mit Bildern und persönlicher Vorstellung
- Responsive Ansichten und Berücksichtigung reduzierter Bewegung

## Kontaktformular

Das Kontaktformular ist vorbereitet, aber noch nicht zum Versenden freigeschaltet. In `index.html` ist `data-recipient` bewusst leer. Sobald dort eine Kontaktadresse hinterlegt wird, kann das Formular eine E-Mail im lokalen E-Mail-Programm vorbereiten. Es gibt keinen Backend-Versand.

## Assets

Originale Projektlogos stammen von den verlinkten Websites; Herkunftshinweise stehen in `assets/portfolio/SOURCES.md`. Die Timeline verwendet generierte Symbolbilder, siehe `assets/timeline/SOURCES.md`.
